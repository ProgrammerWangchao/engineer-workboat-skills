# AGENTS.md 模板

# 项目目标

用一小段说明产品服务对象和当前目标。不要在这里粘贴完整需求。

## 长期规则

- 只保留跨任务稳定、少数且必须遵守的工程规则。
- 标明危险或外部动作的授权边界。

## 资料入口

仅列出真实存在的文件，并说明各自权威范围：

- 产品规格：`<真实路径>`
- 技术设计：`<真实路径>`
- 执行计划或功能清单：`<真实路径>`
- 最近交接：`<真实路径>`

## 按任务读取

- 新需求：先读项目目标、相关产品规格和最近交接。
- 实现：再读技术设计、功能清单和相关源码。
- 验收：读取实际版本、验收标准和功能入口，保持独立判断。
- Review：读取需求、实际差异和已有验证证据。

## 存放约定

说明后续产品、设计、原型、计划、交接和参考资料应放在哪里。未来目录不是已有文件链接，不批量创建空文件。
